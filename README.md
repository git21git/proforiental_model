# Анализ факторов выбора профессии школьниками

Учебный проект Марии Чудиновой по технологиям машинного обучения. Исследование охватывает обработку анкет, разведочный анализ, классификацию, проверку качества и пакетное обновление аналитического отчёта.

- [HTML-отчёт](index.html) содержит сводные графики, метрики и пример отображения результатов. Скачайте файл и откройте в браузере.
- [Демонстрация Power BI](power-bi-demo.zip) содержит три интерактивные страницы на вымышленных записях. Распакуйте архив, откройте Guidance.pbip в Power BI Desktop и нажмите «Обновить».

**Инструменты:** Python, scikit-learn, SQLite, Power BI Desktop. Из 125 заполненных анкет отобраны 104. Для прототипа выбрана логистическая регрессия с проверяемым расчётом трёх баллов. Macro-F1 на 13 отложенных анкетах составил 0,645. Результаты будут использованы во втором сезоне проекта «Абитуриент — студент: твой маршрут».
